## Important: Read the assignment documents carefully

Read each assignment document very carefully, especially the deliverables section, and check every submission requirement against it before advising what to submit. On Assignment 1 the grade was 85 instead of 95 because I was told to submit only the images shown on the website (6 completed images). The website only needed to show 6, but all the other results also had to be included in the submission package. Keep "what the website must show" separate from "what the submission package must contain".
